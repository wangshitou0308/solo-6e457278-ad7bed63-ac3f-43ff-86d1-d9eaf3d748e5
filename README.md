# 铅字归还助手

活字印刷工坊拆版后归还铅字的本地 Web 工具。纯标准库实现，**断网即可运行**：
后端为 Python `http.server` + `sqlite3`，前端为原生 HTML / CSS / JavaScript，
字盘用 SVG 绘制，无任何外部依赖与 CDN。

## 启动

```bash
python3 server.py          # 默认端口 8000
python3 server.py 9000     # 指定端口
```

浏览器打开 <http://127.0.0.1:8000>。数据保存在同目录 `sortify.db`
（可用环境变量 `SORTIFY_DB` 指定路径）。首次启动自动生成示例字盘。

运行自测（使用临时数据库，不影响正式数据）：

```bash
python3 test_api.py
```

## 功能与用法

### 1. 字盘编辑（搭建不规则格位）

- 在 SVG 画布上**拖动格子**照实物字盘摆位，松手自动保存坐标；
- 点击格子，在右侧编辑**格号、字符、字体、字号、当前数量、容量、宽高**；
- 「新建格位」逐个添加；「批量成行」一次生成一排空格位；
- 字符留空即**空格位**，供归还时改派使用。

### 2. 归还作业

1. 粘贴待归还清单，每行一条：
   - `永 12`、`永×12`、`永*12`、`永,12,宋体,五号`、`永 12 宋体 五号`
   - 数量缺省为 1；字体、字号可省略（省略时按字符匹配）。
2. 「解析并创建批次」后，系统按**字符 + 字体 + 字号**匹配格位，
   同一目标格的数量自动**合成一批**，并按坐标**蛇形（之字形）规划取放顺序**，
   逐行往返、减少走动。
3. 字盘高亮：**橙色＝当前格，蓝色＝下一格，绿色＝已完成**，
   格上角标显示**本批余量**；右侧面板显示当前字、目标格与进度。
4. **扫描格位标签或键盘输入格号后回车**确认（空回车＝确认当前格）；
   可在数量框填入本次实际放入枚数（默认全部）。
5. 快捷键：`U` 撤销最近一次确认。

### 3. 异常暂停与改派

- **格位已满**：暂停并列出候选格（同字符格优先，其次空格位），
  并排展示**改派前后的位置与容量变化**，确认「改派并放入」后才换格；
  放入数量**严格采用数量框中本次填写的枚数**（未填则为全部剩余），
  预览随填写实时变化；也可「强制放入原格」（允许超容，会在容量检查中标红）。
- **空格位首次接收铅字时自动登记字种**（字符 / 字体 / 字号），
  之后该字种即可正常匹配到此格。
- **实物不符**（扫到别的格）：展示应为 / 扫描到两格对比，
  确认实物确属扫描格后改派；若是**重复确认**（该格本批已完成）会额外提示。
- **无法识别的格号**：提示后重新扫描。

### 4. 待确认

合字（多字铸体）、异体字（内置常见对照表，给出正字建议）、
无法辨认（`?`）以及字盘中无匹配格的铅字，自动暂列「待确认」页。
指定目标格「归位」后追加到当前归还批次（无批次时自动建补录批次），或「忽略」。

### 5. 数据

- **容量冲突检查**：已超容格位 + 当前批次预计超容格位；
- **打印临时分拣标签**：按取放顺序生成带格号、字符、字体字号、数量、
  坐标与批次号的标签，浏览器打印后裁剪使用；
- **JSON 备份 / 恢复**：一键导出全部数据；恢复会覆盖当前数据。

### 6. 中断续做与撤销

批次状态实时写入 SQLite：关浏览器、断电后重开页面自动恢复到上次进度。
「撤销」回滚最近一次确认（格内数量与任务状态一并回退）。
**批次完成后收尾操作仍然保留**：完成页可撤销最后一次确认（批次随即恢复进行中）、
补打本批标签，下方粘贴区可直接开始新清单；数据页也能补打最近完成批次的标签。

## 文件结构

```
server.py          后端：HTTP 服务、SQLite 存储、匹配/规划/冲突逻辑
static/index.html  页面骨架
static/style.css   样式（含打印标签的 @media print）
static/app.js      前端：SVG 字盘、拖拽编辑、作业流程、冲突处理
test_api.py        API 流程自测（55 项）
```

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全量状态（格位 / 当前批次 / 待确认 / 容量冲突） |
| POST | `/api/cells` · `/api/cells/bulk` | 新建 / 批量新建格位 |
| PUT / DELETE | `/api/cells/{id}` | 更新（含拖拽坐标）/ 删除格位 |
| POST | `/api/sessions` | 粘贴文本解析并创建归还批次 |
| POST | `/api/sessions/{id}/finish` · `abandon` · `undo` | 完成 / 作废 / 撤销最近确认 |
| POST | `/api/tasks/{id}/confirm` · `reassign` · `skip` | 确认 / 改派 / 跳过 |
| POST | `/api/pending/{id}/resolve` | 待确认项归位或忽略 |
| GET / POST | `/api/backup` · `/api/restore` | JSON 备份 / 恢复 |
