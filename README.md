# 铅字归还助手 · 多字盘换盘导航

活字印刷工坊拆版后归还铅字的本地 Web 工具。纯标准库实现，**断网即可运行**：
后端为 Python `http.server` + `sqlite3`，前端为原生 HTML / CSS / JavaScript，
字盘用 SVG 绘制，无任何外部依赖与 CDN。

支持管理**多个实体字盘**：每个字盘可命名、设置扫描码、单独编辑不规则布局；
归还批次先按目标字盘归组，再在盘内蛇形规划格位次序。执行页一次只画当前盘，
跨盘前必须扫描实体字盘上的字盘码核对，扫错立即暂停对照，确认换盘后才激活首格。

## 启动

```bash
python3 server.py          # 默认端口 8000
python3 server.py 9000     # 指定端口
```

浏览器打开 <http://127.0.0.1:8000>。数据保存在同目录 `sortify.db`
（可用环境变量 `SORTIFY_DB` 指定路径）。首次启动自动生成「默认字盘」示例；
**旧版单字盘数据库会在启动时自动升级**，原有格位与历史批次全部归入默认字盘。

运行自测（使用临时数据库，不影响正式数据）：

```bash
python3 test_api.py
```

## 功能与用法

### 1. 字盘管理与布局编辑（多实体字盘）

- 顶部字盘栏可**新建 / 切换 / 排序 / 复制 / 删除**字盘，并设置
  **字盘名称**与**扫描码**（贴在实体字盘上的条码 / 二维码内容，如 `TRAY-02`）；
- 在 SVG 画布上**拖动格子**照实物摆位，松手自动保存坐标；
- 点击格子，在右侧编辑**格号、字符、字体、字号、当前数量、容量、宽高**；
- 「新建格位」逐个添加；「批量成行」向当前字盘生成一排空格位；
- **格号只需在同一字盘内唯一**，不同字盘允许同号；
- 字符留空即**空格位**，供归还时同盘改派使用；
- **「复制此盘布局」只复制格位结构**（格号 / 坐标 / 尺寸 / 字种 / 容量），
  **不带存量**，副本盘数量全部为 0。

### 2. 归还作业：先归组、再盘内规划，锁定换盘顺序

1. 粘贴待归还清单，每行一条：
   - `永 12`、`永×12`、`永*12`、`永,12,宋体,五号`、`永 12 宋体 五号`
   - 数量缺省为 1；字体、字号可省略（省略时按字符匹配）。
2. 「解析并创建批次」后进入**换盘规划页**：
   - 系统先按**字符 + 字体 + 字号**把任务**归入各自目标字盘**，
     同一目标格的数量自动合并；
   - 再在**每个字盘内**按坐标**蛇形（之字形）规划**取放顺序，盘内序号各自从 1 起；
   - 可上下调整**换盘顺序**、单选**起始盘**；
   - 「锁定顺序，开始执行」后顺序不可再改，批次进入执行态。
3. **起始盘也必须先扫描字盘码**：确认换盘后该盘首个格位才激活。

### 3. 执行页与跨盘闸门

- 执行页**只绘制当前字盘**，橙色＝当前格、蓝色＝盘内下一格、绿色＝已完成，
  角标显示本批余量；
- 侧栏始终提示**下一字盘**（名称 + 字盘码）与**剩余任务数 / 枚数**，
  下方「换盘与格位顺序」按盘分组展示各盘进度；
- 盘内最后一格做完后进入**换盘闸门**：不激活任何格位，要求扫描实体字盘码；
- **扫错字盘码立即暂停**，并排对照**预期字盘与实际扫到的字盘**（名称 / 字盘码），
  换成正确字盘重新扫描即可；无法识别的码同样拦截；
- 核对通过、「确认换盘」后，新盘的**第一个格位**才高亮激活；
- **扫描格号只认当前字盘**：扫到别的盘的格号会报 `wrong_tray`，
  盘内扫错格仍按实物不符（mismatch）处理；
- 数量框可填本次实际放入枚数（默认全部）；快捷键 `U` 撤销最近一次确认。

### 4. 异常暂停与同盘改派

- **格位已满**：暂停并列出**同字盘**候选格（同字符格优先，其次空格位），
  并排展示改派前后的位置与容量变化，确认「改派并放入」后才换格；
  不允许跨字盘改派——跨盘必须走换盘闸门；
- **空格位首次接收铅字时自动登记字种**（字符 / 字体 / 字号）；
- **实物不符**（盘内扫到别的格）：展示应为 / 扫描到两格对比，
  确认实物确属扫描格后同盘改派；重复确认会额外提示；
- **无法识别的格号 / 格号属于别的字盘**：提示后重新扫描。

### 5. 待确认

合字、异体字、无法辨认（`?`）以及无匹配格的铅字自动列入「待确认」页。
指定目标格「归位」后追加到当前批次**该格所属字盘**的顺序末尾
（批次未锁定时可继续在规划页调整；无批次时自动建补录批次），或「忽略」。

### 6. 数据

- **容量冲突检查**：已超容格位 + 当前批次预计超容格位，均标注字盘归属；
- **打印临时分拣标签**：按换盘顺序与盘内次序生成标签，每张同时印出
  **字盘名、字盘码与格号**，以及字符、字体字号、数量、盘内次序与批次号；
- **JSON 备份 / 恢复（v2）**：备份包含全部字盘及格位归属，恢复会覆盖当前数据；
  恢复 **v1 旧备份**时自动建立「默认字盘」并把全部格位、批次归入其中。

### 7. 中断续做、撤销与换盘恢复

- 当前盘、**锁定的换盘顺序**、各盘任务进度与**闸门等待状态**全部写入 SQLite，
  刷新 / 断电 / 重开浏览器后自动恢复到原来的盘与闸门；
- 「撤销」回滚最近一次确认：格内数量、任务状态、**当前执行盘**一并回退，
  撤到跨盘前的任务时直接回到该任务所在字盘，无需重新扫盘；
- 批次完成后仍可撤销最后一次确认（批次恢复执行）、补打本批标签。

## 文件结构

```
server.py          后端：HTTP 服务、SQLite 存储、多字盘模型、归组/规划/闸门/冲突
static/index.html  页面骨架（字盘栏、规划页、执行页、换盘闸门）
static/style.css   样式（含打印标签的 @media print）
static/app.js      前端：SVG 字盘、拖拽编辑、换盘规划、扫码闸门、冲突处理
test_api.py        API 流程自测（92 项）
```

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全量状态（字盘 / 格位 / 当前批次 / 待确认 / 冲突） |
| POST | `/api/trays` · `/api/trays/reorder` | 新建字盘 / 调整字盘显示顺序 |
| PUT / DELETE | `/api/trays/{id}` | 改名 / 设扫描码 / 删除字盘 |
| POST | `/api/trays/{id}/duplicate` | 复制布局（只带结构，不带存量） |
| POST | `/api/cells` · `/api/cells/bulk` | 新建 / 批量新建格位（带 `tray_id`，盘内格号唯一） |
| PUT / DELETE | `/api/cells/{id}` | 更新（含拖拽坐标）/ 删除格位 |
| POST | `/api/sessions` | 粘贴文本解析、按字盘归组建批次（进入规划态） |
| POST | `/api/sessions/{id}/plan` | 调整换盘顺序 / 指定起始盘 / 锁定开始执行 |
| POST | `/api/sessions/{id}/confirm-tray` | 跨盘闸门：扫描字盘码核对并确认换盘 |
| POST | `/api/sessions/{id}/finish` · `abandon` · `undo` | 完成 / 作废 / 撤销最近确认 |
| POST | `/api/tasks/{id}/confirm` · `reassign` · `skip` | 确认（只认当前盘格号）/ 同盘改派 / 跳过 |
| POST | `/api/pending/{id}/resolve` | 待确认项归位（追加到对应字盘）或忽略 |
| GET / POST | `/api/backup` · `/api/restore` | JSON v2 备份 / 恢复（兼容 v1） |
