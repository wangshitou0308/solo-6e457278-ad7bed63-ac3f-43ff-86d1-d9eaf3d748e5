# 铅字归还助手 · 多字盘换盘导航（含印前配字领用）

活字印刷工坊拆版后归还铅字、印前排字前领用铅字的本地 Web 工具。纯标准库实现，**断网即可运行**：
后端为 Python `http.server` + `sqlite3`，前端为原生 HTML / CSS / JavaScript，
字盘用 SVG 绘制，无任何外部依赖与 CDN。

支持管理**多个实体字盘**：每个字盘可命名、设置扫描码、单独编辑不规则布局；
归还批次先按目标字盘归组，再在盘内蛇形规划格位次序。执行页一次只画当前盘，
跨盘前必须扫描实体字盘上的字盘码核对，扫错立即暂停对照，确认换盘后才激活首格。

## 启动

```bash
python3 server.py          # 默认端口 8000
python3 server.py 9000     # 指定端口
```

浏览器打开 <http://127.0.0.1:8000>。数据保存在同目录 `sortify.db`
（可用环境变量 `SORTIFY_DB` 指定路径）。首次启动自动生成「默认字盘」示例；
**旧版单字盘数据库会在启动时自动升级**，原有格位与历史批次全部归入默认字盘。

运行自测（使用临时数据库，不影响正式数据）：

```bash
python3 test_api.py
```

## 功能与用法

### 1. 字盘管理与布局编辑（多实体字盘）

- 顶部字盘栏可**新建 / 切换 / 排序 / 复制 / 删除**字盘，并设置
  **字盘名称**与**扫描码**（贴在实体字盘上的条码 / 二维码内容，如 `TRAY-02`）；
  扫描码**不能为空、全局唯一（大小写不敏感）**：新建 / 复制时自动分配，
  编辑为空或与其他字盘重复会被拒绝并回滚输入；启动与备份恢复时会自动修复
  既有脏数据（空码补齐、重复码保留首个并给其余重新分配），并以唯一索引兜底；
- 在 SVG 画布上**拖动格子**照实物摆位，松手自动保存坐标；
- 点击格子，在右侧编辑**格号、字符、字体、字号、当前数量、容量、宽高**；
- 「新建格位」逐个添加；「批量成行」向当前字盘生成一排空格位；
- **格号只需在同一字盘内唯一**，不同字盘允许同号；
- 字符留空即**空格位**，供归还时同盘改派使用；
- **「复制此盘布局」只复制格位结构**（格号 / 坐标 / 尺寸 / 字种 / 容量），
  **不带存量**，副本盘数量全部为 0。

### 2. 归还作业：先归组、再盘内规划，锁定换盘顺序

1. 粘贴待归还清单，每行一条：
   - `永 12`、`永×12`、`永*12`、`永,12,宋体,五号`、`永 12 宋体 五号`
   - 数量缺省为 1；字体、字号可省略（省略时按字符匹配）。
2. 「解析并创建批次」后进入**换盘规划页**：
   - 系统先按**字符 + 字体 + 字号**把任务**归入各自目标字盘**，
     同一目标格的数量自动合并；
   - 再在**每个字盘内**按坐标**蛇形（之字形）规划**取放顺序，盘内序号各自从 1 起；
   - 可上下调整**换盘顺序**、单选**起始盘**；
   - 规划页会对**缺码 / 重复码**的字盘逐行标红，此时锁定按钮禁用并给出
     「请到字盘编辑页设置」的提示；所有涉及字盘都具备非空唯一扫描码后才可锁定；
   - 「锁定顺序，开始执行」后顺序不可再改，批次进入执行态。
3. **起始盘也必须先扫描字盘码**：确认换盘后该盘首个格位才激活。

### 3. 执行页与跨盘闸门

- 执行页**只绘制当前字盘**，橙色＝当前格、蓝色＝盘内下一格、绿色＝已完成，
  角标显示本批余量；
- 侧栏始终提示**下一字盘**（名称 + 字盘码）与**剩余任务数 / 枚数**，
  下方「换盘与格位顺序」按盘分组展示各盘进度；
- 盘内最后一格做完后进入**换盘闸门**：不激活任何格位，要求扫描实体字盘码；
- **扫错字盘码立即暂停**，并排对照**预期字盘与实际扫到的字盘**（名称 / 字盘码），
  换成正确字盘重新扫描即可；无法识别的码同样拦截；
- 核对通过、「确认换盘」后，新盘的**第一个格位**才高亮激活；
- **扫描格号只认当前字盘**：扫到别的盘的格号会报 `wrong_tray`，
  盘内扫错格仍按实物不符（mismatch）处理；
- 数量框可填本次实际放入枚数（默认全部）；快捷键 `U` 撤销最近一次确认。

### 4. 异常暂停与同盘改派

- **格位已满**：暂停并列出**同字盘**候选格（同字符格优先，其次空格位），
  并排展示改派前后的位置与容量变化，确认「改派并放入」后才换格；
  不允许跨字盘改派——跨盘必须走换盘闸门；
- **空格位首次接收铅字时自动登记字种**（字符 / 字体 / 字号）；
- **实物不符**（盘内扫到别的格）：展示应为 / 扫描到两格对比，
  确认实物确属扫描格后同盘改派；重复确认会额外提示；
- **无法识别的格号 / 格号属于别的字盘**：提示后重新扫描。

### 5. 待确认

合字、异体字、无法辨认（`?`）以及无匹配格的铅字自动列入「待确认」页。
指定目标格「归位」后追加到当前批次**该格所属字盘**的顺序末尾
（批次未锁定时可继续在规划页调整；无批次时自动建补录批次），或「忽略」。

### 6. 实体盘点与差异复核

在「实体盘点」页扫描实体字盘上的**字盘码**开始盘点（也可从进行中盘点单继续）：

- **盘锁**：盘点开始即锁住该字盘的**归还确认**与**存量 / 格位编辑**，
  其他字盘不受影响；入账或取消后解锁。
- **按高亮顺序扫描格号并填实数**：盘内扫错格、扫到别的字盘的格号、
  无法识别的格号都会拦截；刷新后自动从**尚未盘点的格位**继续，
  可用「撤销上一格」回退最后一次录入。
- **实物规格三项独立**：字符、字体、字号哪一项与账面不同就只填哪一项，
  其余留空按账面；**只改字体或只改字号（字符留空）也会计为规格不符**。
- **待复核**：混字、无法辨认、暂时不能盘点的格位单列为待复核，
  可在差异复核阶段「复盘」拉回重扫（该格已有盘盈 / 盘亏决议或移格任务时需先撤销）。
- 全盘录完进入**差异复核**，按格列出**短缺、溢出、待复核**；
  **同一规格在不同格位出现相反差额**时只列**错放候选**（来源格 → 目标格 + 数量），
  **不自动改库存**。
- 差异处理：把剩余差额**认定盘盈 / 盘亏**（未入账可撤销），
  或对错放候选**生成移格任务**——执行时必须**依次复扫来源格、目标格**
  （顺序或格号错误即拦截）；也可对候选「核销」为盘盈 / 盘亏。
- **全部差异处理后预览库存变化**（每格账面值、实物、移格出入、入账后值与规格变更），
  再**一次性入账**，逐格保留**盘点前后值**；入账后决议不可撤销。
- **JSON 备份 / 恢复包含盘点记录与移格任务进度**，并可**打印差异单**
  （按格短缺 / 溢出 / 规格不符 / 错放候选 / 待复核，含签字栏）。

### 7. 数据

- **容量冲突检查**：已超容格位 + 当前批次预计超容格位，均标注字盘归属；
- **打印临时分拣标签**：按换盘顺序与盘内次序生成标签，每张同时印出
  **字盘名、字盘码与格号**，以及字符、字体字号、数量、盘内次序与批次号；
- **JSON 备份 / 恢复（v4）**：备份包含全部字盘、格位归属以及
  **盘点单、格位快照、差异 / 决议、错放候选、移格任务与入账前后值**，以及
  **配字领用单的需求、预留 / 改选 / 缺口分配、实取数量与来源格**，
  恢复会覆盖当前数据；恢复 **v3 / v2 / v1 旧备份**时仍可读取，
  v1 自动建立「默认字盘」并把全部格位、批次归入其中。

### 8. 印前配字领用（配字视图）

在「配字领用」页为印前排字领料：

1. **汇总需求**：粘贴整段**待排文字**（逐字计数），或切换为
   「字符、数量、字体、字号」清单（写法同归还清单）；可分别选择
   **是否计入空格、是否计入标点**。系统按 字符+字体+字号 汇总总需求。
2. **多盘同规格分配**：从多个字盘的同规格格位分配可用铅字（贪心：可用量大的
   格位优先，再按字盘顺序、盘内蛇形），并**扣除其他未完成领用单的预留量**。
   - **数量不足**：列出需求、已配与缺口数，缺口不锁格；
   - **仅有异体字**（如只有正字「体」没有「體」）、**规格不符**（字体 / 字号
     不同）分别单列，**不自动替换**。
3. **锁定来源格**后领用单按字盘分组、盘内蛇形路线执行：
   - 每次换盘先**扫描字盘码**核对（扫错 / 无法识别即暂停对照），通过后激活首格；
   - 扫描格号并**确认实取数量**；少取时可**改选同盘另一来源格**（异体 / 异规格
     不自动替换，跨盘必须走换盘闸门）或**保留缺口**；**确认前不扣库存**；
   - 页面进度随时保存（刷新自动续做），可**撤销上一笔**、**取消领用单**
     （未取预留全部释放，已实取保留记录）。
4. **领用清单与标签**：完成后打印领用单，含每张领用单的**预留、改选实取、
   实取、缺口与来源格**；来源格标签逐张印出本格预留与实取数量，清单与标签
   数量一致。可**一键带入现有归还流程**，生成规划态归还批次——
   **归还仍需逐格扫码确认**。
5. 改选 / 缺口在数据上是父计划分配的子行（`kind=change/gap`），预留合计
   只计计划行，避免父子行重复相加。

### 9. 中断续做、撤销与换盘恢复

- 当前盘、**锁定的换盘顺序**、各盘任务进度与**闸门等待状态**全部写入 SQLite，
  刷新 / 断电 / 重开浏览器后自动恢复到原来的盘与闸门；
- 「撤销」回滚最近一次确认：格内数量、任务状态、**当前执行盘**一并回退，
  撤到跨盘前的任务时直接回到该任务所在字盘，无需重新扫盘；
- 批次完成后仍可撤销最后一次确认（批次恢复执行）、补打本批标签。

## 文件结构

```
server.py          后端：HTTP 服务、SQLite 存储、多字盘模型、归组/规划/闸门/冲突、实体盘点/差异复核/移格/入账、配字领用/预留/改选/缺口/带入归还
static/index.html  页面骨架（字盘栏、配字领用、规划页、执行页、换盘闸门、实体盘点）
static/style.css   样式（含打印标签、领用单与盘点差异单的 @media print）
static/app.js      前端：SVG 字盘、拖拽编辑、换盘规划、扫码闸门、冲突处理、配字领用、盘点扫码 / 差异复核 / 移格复扫
test_api.py        API 流程自测（220 项）
```

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 全量状态（字盘 / 格位 / 当前批次 / 待确认 / 冲突 / 进行中盘点单 / 当前领用单） |
| POST | `/api/trays` · `/api/trays/reorder` | 新建字盘 / 调整字盘显示顺序 |
| PUT / DELETE | `/api/trays/{id}` | 改名 / 设扫描码 / 删除字盘 |
| POST | `/api/trays/{id}/duplicate` | 复制布局（只带结构，不带存量） |
| POST | `/api/cells` · `/api/cells/bulk` | 新建 / 批量新建格位（带 `tray_id`，盘内格号唯一；盘点中被锁） |
| PUT / DELETE | `/api/cells/{id}` | 更新（含拖拽坐标）/ 删除格位（盘点中被锁） |
| POST | `/api/sessions` | 粘贴文本解析、按字盘归组建批次（进入规划态） |
| POST | `/api/sessions/{id}/plan` | 调整换盘顺序 / 指定起始盘 / 锁定开始执行 |
| POST | `/api/sessions/{id}/confirm-tray` | 跨盘闸门：扫描字盘码核对并确认换盘 |
| POST | `/api/sessions/{id}/finish` · `abandon` · `undo` | 完成 / 作废 / 撤销最近确认 |
| POST | `/api/tasks/{id}/confirm` · `reassign` · `skip` | 确认（只认当前盘格号，盘点中被锁）/ 同盘改派 / 跳过 |
| POST | `/api/pending/{id}/resolve` | 待确认项归位（追加到对应字盘）或忽略 |
| POST | `/api/stocktakes` | 扫描字盘码开始盘点（建快照、按蛇形排序、锁盘） |
| GET | `/api/stocktakes/{id}` | 盘点单详情（快照 / 差异 / 错放候选 / 移格 / 入账预览） |
| POST | `/api/stocktakes/{id}/count` | 扫描当前格号录入实数 / 实物规格 / 待复核标记 |
| POST | `/api/stocktakes/{id}/undo-count` | 撤销最近一格录入（复核态则退回盘点中） |
| POST | `/api/stocktakes/{id}/recheck` | 差异复核阶段把格拉回复盘 |
| POST | `/api/stocktakes/{id}/cancel` · `post` | 取消盘点单（解锁）/ 一次性入账 |
| POST | `/api/discrepancies/{id}/decide` · `revoke` | 认定盘盈 `gain` / 盘亏 `loss`，或撤销未入账决议 |
| POST | `/api/pairs/{id}/move` · `writeoff` · `revoke` | 错放候选生成移格任务 / 核销为盘盈盘亏 / 撤销 |
| POST | `/api/move-tasks/{id}/scan` · `cancel` | 依次复扫来源格、目标格；或取消移格任务 |
| POST | `/api/requisitions` | 粘贴待排文字 / 清单，汇总需求并从多盘同规格格位分配（扣其他单预留），返回不足 / 异体 / 规格不符 |
| GET | `/api/requisitions/{id}` | 领用单详情（需求、计划 / 改选 / 缺口分配、实取、来源格、汇总） |
| POST | `/api/requisitions/{id}/plan` | 锁定来源格与盘内路线开始执行 |
| POST | `/api/requisitions/{id}/confirm-tray` | 换盘闸门：扫描字盘码核对后激活首格 |
| POST | `/api/requisitions/{id}/pick` | 扫描格号确认实取数量（少取 / 扫错出冲突，确认前不扣库存） |
| POST | `/api/requisitions/{id}/change-source` · `keep-gap` | 少取后改选同盘另一来源格 / 保留差额为缺口 |
| POST | `/api/requisitions/{id}/finish` · `cancel` · `undo` | 完成 / 取消（释放未取预留）/ 撤销上一笔 |
| POST | `/api/requisitions/{id}/to-return` | 完成单按实取数量带入现有归还流程（仍需逐格扫码） |
| GET / POST | `/api/backup` · `/api/restore` | JSON v4 备份 / 恢复（含领用单、盘点记录与任务进度，兼容 v1 / v2 / v3） |
